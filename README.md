# Instapro

MVP социальной сети для обмена фотографиями

Функционал который удалось реализовать:
1) Интеграция верстки списка постов с API
2) Реализация страницы добавления поста
    - настроена защита от отправки в текстовое поле html-кода
    - настроены уведомления при отправке формы без описания или загруженного изображения
3) Реализация страницы с постами отдельного пользователя
4) Реализация функции лайков
    - если лайк ставится на странице с постами отдельного пользователя, то после перерисовки страницы пользователь остаётся на той же странице, а не переносится на общую страницу

Реализовано дополнительно:
1) Удаление поста
    - Пост может удалить только авторизованный пользователь
    - Пользователь может удалить только те посты которые добавил он сам, чужие посты он удалить не может
    - Меню с кнопкой удаления доступна только на странице пользователя с его постами
2) Анимация кнопки лайка при нажатии на неё и ожидании результата с сервера
    - анимация работает только если пользователь авторизован
3) Добавлена адаптивность под разные размеры экрана
    - для десктопной версии возвращена полоса прокрутки
